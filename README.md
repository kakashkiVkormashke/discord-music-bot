# Музыкальный бот Discord — Python 3.11

Обрабатывает новые сообщения только в канале 1429229290540503061. Историю не читает, сообщения других ботов игнорирует. Для строгой изоляции в Discord выдайте View Channel только для нужного текстового канала и необходимых голосовых каналов.

Любое обычное сообщение — запрос поиска YouTube. Также принимает «включи название», «поставь название» и прямую ссылку на видео YouTube. В голосовом канале проигрывается только аудио. Плейлисты целиком не добавляются. Поиск выбирает первый результат, без отдельного ИИ и платных API.

Фразы: «включи следующий», «следующий», «скип»; «останови музыку», «стоп» (очистить очередь и выйти); «пауза», «поставь на паузу»; «продолжи», «сними с паузы»; «очередь», «покажи очередь». Названия, совпадающие с командами, задавайте ссылкой или через «включи название».

Участник должен находиться в обычном голосовом канале. Если бот уже подключён, заказывать и управлять могут только участники этого же канала. После окончания очереди бот остаётся подключённым до «стоп». Очередь хранится в памяти, при перезапуске сбрасывается. Пропуск во время поиска сработает после завершения текущего запроса к YouTube.

## Настройка Discord

1. Создайте приложение и бота в https://discord.com/developers/applications.
2. На странице Bot включите Message Content Intent.
3. Сохраните токен в переменную окружения DISCORD_TOKEN на хостинге. Не публикуйте токен в Git и не отправляйте в чат.
4. Пригласите бота с OAuth2 scope `bot` и правами View Channel, Send Messages, Connect, Speak. Administrator не требуется.
5. Проверьте разрешения именно нужного текстового канала и голосовых каналов.

## Хостинг

Для Bothost.ru: в «Дополнительных настройках» включите «Использовать собственный Dockerfile». Файл запуска — `bot.py`, версия Python — 3.11, ветка — main. Без этой галочки платформа может заменить наш Dockerfile автогенерируемым и не установить Deno. Документация: https://bothost.ru/docs/custom-dockerfile.

Переменные окружения:

```text
DISCORD_TOKEN=токен_бота
TEXT_CHANNEL_ID=1429229290540503061
```

Загрузите содержимое этой папки в корень Git-репозитория, ветка main. Укажите URL репозитория на хостинге. Если поддерживается Docker — используйте приложенный Dockerfile: он устанавливает Python 3.11, FFmpeg, Deno и зависимости. Тип процесса — постоянный worker, без HTTP-порта. Запускать одну копию бота.

Без Docker на сервере должны быть Python 3.11, FFmpeg с libopus и Deno в PATH. Команда установки: `python -m pip install -r requirements.txt`. Команда запуска: `python -u bot.py`. Для локального запуска можно скопировать `.env.example` в `.env` и заполнить токен.

Хостинг должен разрешать исходящие соединения Discord/YouTube и UDP для голоса. YouTube иногда блокирует IP дата-центров или отдельные видео; работоспособность на выбранном сервере проверяется при развёртывании. Первое действие при изменениях YouTube — обновление yt-dlp и пересборка образа.

## Проверка после запуска

Проверьте: сообщение в другом канале игнорируется; запрос без голосового канала получает подсказку; два запроса играют по очереди; пауза/продолжение работают; следующий переключает трек; стоп очищает очередь и отключает бота; участник другого голосового канала не может менять воспроизведение.

Полный тест Discord и YouTube пока не выполнен: нужны токен и доступ к хостингу. Локальный запуск и автоматические тесты также не выполнены: в рабочем окружении не обнаружены Python и Docker.

Документация зависимостей: https://discordpy.readthedocs.io/en/stable/whats_new.html и https://github.com/yt-dlp/yt-dlp/wiki/EJS.
