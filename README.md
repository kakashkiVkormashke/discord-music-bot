# Музыкальный бот Discord — Python 3.11

Бот может работать на нескольких серверах. На каждом сервере он слушает только один музыкальный текстовый канал. Сообщения в других каналах игнорируются. Историю не читает, сообщения других ботов игнорирует.

Самый простой способ для нового сервера — создать или переименовать текстовый канал так, чтобы его название заканчивалось на `_ms`, например `music_ms`, `музыка_ms` или `bot_ms`. Бот автоматически будет слушать такой канал на любом сервере, куда он добавлен.

Любое обычное сообщение в музыкальном канале — запрос поиска YouTube. Также принимает «включи название», «поставь название», прямую ссылку на видео и ссылку на плейлист. В голосовом канале проигрывается только аудио. Поиск выбирает первый результат.

Плейлисты грузятся порциями, чтобы не забивать очередь и не грузить хостинг. По умолчанию первая ссылка на плейлист добавляет 25 треков. Когда они закончатся или когда захочется докинуть ещё, напишите «дальше», «ещё», «следующие», «загрузи дальше» или «докинь плейлист» — бот добавит следующую порцию из того же плейлиста.

Плейлисты достаются через yt-dlp. YouTube-плейлисты должны работать стабильно. VK, SoundCloud и другие сайты будут работать только если yt-dlp умеет достать этот публичный плейлист без входа в аккаунт и cookies.

Фразы управления: «включи следующий», «следующий», «скип»; «останови музыку», «стоп»; «пауза», «поставь на паузу»; «продолжи», «сними с паузы»; «очередь», «покажи очередь»; «дальше», «ещё», «следующие», «загрузи дальше», «докинь плейлист».

## Настройка канала на сервере

Рекомендуемый вариант: назовите музыкальный текстовый канал с окончанием `_ms`. Тогда ничего писать боту не нужно.

Если нужен ручной выбор канала, напишите на сервере:

```text
lool channel_id
```

Пример:

```text
lool 123456789012345678
```

Команду может выполнить только участник с правом `Manage Server` или `Administrator`. Бот должен видеть канал с указанным ID. После настройки он будет слушать только этот канал на этом сервере.

Ручные настройки сохраняются в `channels.json`. Если обычная папка приложения на хостинге закрыта для записи, бот попробует сохранить файл в `/tmp/channels.json`. Если сохранить файл нигде не получится, команда `lool channel_id` всё равно применится до перезапуска. Авто-каналы с окончанием `_ms` не требуют сохранения файла.

По умолчанию бот также слушает канал из `TEXT_CHANNEL_ID`. Для старого сервера это `1429229290540503061`. Это нужно только для обратной совместимости.

## Настройка Discord

1. Создайте приложение и бота в https://discord.com/developers/applications.
2. На странице Bot включите `Message Content Intent`.
3. Сохраните токен в переменную окружения `DISCORD_TOKEN` на хостинге. Не публикуйте токен в Git и не отправляйте в чат.
4. Пригласите бота с OAuth2 scope `bot` и правами `View Channel`, `Send Messages`, `Connect`, `Speak`.
5. Проверьте разрешения нужных текстовых и голосовых каналов на каждом сервере.

## Хостинг

Для Bothost.ru: в дополнительных настройках включите использование собственного `Dockerfile`. Без этого платформа может заменить Dockerfile автогенерируемым и не установить Deno.

Переменные окружения:

```text
DISCORD_TOKEN=токен_бота
TEXT_CHANNEL_ID=1429229290540503061
CHANNEL_CONFIG_PATH=channels.json
CHANNEL_NAME_SUFFIX=_ms
PLAYLIST_BATCH_SIZE=25
PLAYLIST_MAX_ITEMS=300
```

`CHANNEL_NAME_SUFFIX` — окончание названия канала, который бот будет слушать автоматически. Можно оставить `_ms` и просто создавать каналы вида `название_ms`.

`TEXT_CHANNEL_ID` остаётся дефолтным каналом для старого сервера или для серверов, где нет канала с окончанием `_ms`.

`PLAYLIST_BATCH_SIZE` — сколько треков добавлять из плейлиста за раз. Можно поставить 20 или 30. Больше 50 бот всё равно не возьмёт за одну порцию, потому что очередь ограничена.

`PLAYLIST_MAX_ITEMS` — сколько треков максимум бот запомнит из одного плейлиста. Это защита от огромных плейлистов.

Тип процесса — постоянный worker, без HTTP-порта. Запускать одну копию бота.

Без Docker на сервере должны быть Python 3.11, FFmpeg с libopus и Deno в PATH.

```bash
python -m pip install -r requirements.txt
python -u bot.py
```

## Проверка после запуска

Проверьте: канал с окончанием `_ms` принимает запросы; сообщение в другом канале игнорируется; `lool channel_id` вручную задаёт канал, если нужен override; запрос без голосового канала получает подсказку; два запроса играют по очереди; пауза/продолжение работают; следующий переключает трек; стоп очищает очередь и отключает бота; ссылка на плейлист добавляет первую порцию; команда «дальше» добавляет следующую порцию.
